# Genomic Sequence Analyzer

## Run locally

```bash
python -m streamlit run streamlit_app.py
```

Use **Use Example** to run the bundled sequence, or select **Custom Sample** to
paste a DNA sequence in plain text or FASTA format. Select **Analyze sequence**
to start the workflow, then approve each stage before moving to the next one.

The interface follows the browser or operating-system light/dark preference.
